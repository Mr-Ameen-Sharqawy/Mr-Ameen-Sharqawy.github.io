# مقارنة النسخة الأصلية ونسخة GitHub Pages

تمت مراجعة النسختين على سطح المكتب لصفحة اختيار الصف، كما تمت مراجعة GitHub Pages على الهاتف لصفحة اختيار الصف وشاشة الدروس والبطاقة.

| المسار | النسخة الأصلية | GitHub Pages | النتيجة |
|---|---|---|---|
| اختيار الصف | بوابة RTL هادئة تشمل هوية Vocabulary Journey وثلاث بطاقات للصفوف 4–6 وألوان الأصفر والنعناعي واللافندر. | يحتفظ بالهوية والبطاقات ونصوص الصفوف وترتيبها البصري، مع واجهة عامة من دون تسجيل دخول. | متوافق بصريًا ووظيفيًا لاختيار رحلة الطالب. |
| الدخول إلى الصف | يطلب اسم مستخدم وكلمة مرور للطالب لحفظ تقدم الحساب على الخادم. | يفتح مسار الصف مباشرة، ويحفظ المراجعة محليًا في المتصفح فقط. | اختلاف مقصود بسبب عدم وجود خادم أو قاعدة بيانات في GitHub Pages. |
| الدروس والبطاقة | تصبح واجهة الدروس متاحة بعد دخول حساب الطالب. | تعرض القائمة والبطاقة والنطق والمعنى والتنقل مباشرة، مع غلاف محلي مميز لكل درس. | يحافظ على تجربة التعلم العامة، لكن لا يوفّر حساب الطالب أو تقدمه المركزي. |
| الصور | الصور الأصلية كانت مراجع تخزين موقعة لم تعد متاحة للاستهلاك العام خارج التطبيق. | تضم 60 غلافًا محليًا للدروس، مشتقة من رسومات تعليمية مخصصة للوحدات. | الصور تعمل داخل GitHub Pages، لكنها أغلفة للدروس وليست رسمًا منفصلًا لكل مفردة. |

> **حدود مقصودة:** بوابة المعلم، حسابات الطلاب، الأجهزة المسموح بها، وحفظ التقدم على الخادم تبقى في النسخة الكاملة. GitHub Pages مخصص للعرض والتعلم الذاتي العام من دون تحويل إلى Manus.
