# مقارنة النسخة الأصلية ونسخة GitHub Pages

تمت مراجعة النسختين على سطح المكتب والهاتف لصفحة اختيار الصف. كما تمت مراجعة GitHub Pages على الهاتف لصفحة الدروس والبطاقة. عند محاولة فتح الصف السادس في النسخة الأصلية، ظهرت شاشة دخول الطالب قبل الوصول إلى قائمة الدروس والبطاقة.

| المسار | النسخة الأصلية | GitHub Pages | النتيجة |
|---|---|---|---|
| اختيار الصف | بوابة RTL هادئة تشمل هوية Vocabulary Journey وثلاث بطاقات للصفوف 4–6 وألوان الأصفر والنعناعي واللافندر. | يحتفظ بالهوية والبطاقات ونصوص الصفوف وترتيبها البصري، مع واجهة عامة من دون تسجيل دخول. | متوافق بصريًا ووظيفيًا لاختيار رحلة الطالب. |
| الدخول إلى الصف | يطلب اسم مستخدم وكلمة مرور للطالب لحفظ تقدم الحساب على الخادم؛ تم التحقق من شاشة الدخول عند فتح الصف السادس. | يفتح مسار الصف مباشرة، ويحفظ المراجعة محليًا في المتصفح فقط. | اختلاف مقصود بسبب عدم وجود خادم أو قاعدة بيانات في GitHub Pages. |
| الدروس والبطاقة | لم تُراجع خلف شاشة الدخول، لأنها تتطلب بيانات حساب طالب صالحة غير متاحة في جلسة المراجعة. | تعرض القائمة والبطاقة والنطق والمعنى والتنقل مباشرة، مع غلاف محلي مميز لكل درس؛ راجعت على سطح المكتب والهاتف. | تحافظ على تجربة التعلم العامة، لكن لا يوفّر GitHub Pages حساب الطالب أو تقدمه المركزي. |
| الصور | الصور الأصلية كانت مراجع تخزين موقعة لم تعد متاحة للاستهلاك العام خارج التطبيق. | تضم 60 غلافًا محليًا للدروس، مشتقة من رسومات تعليمية مخصصة للوحدات. | الصور تعمل داخل GitHub Pages، لكنها أغلفة للدروس وليست رسمًا منفصلًا لكل مفردة. |

> **حدود مقصودة:** بوابة المعلم، حسابات الطلاب، الأجهزة المسموح بها، وحفظ التقدم على الخادم تبقى في النسخة الكاملة. GitHub Pages مخصص للعرض والتعلم الذاتي العام من دون تحويل إلى Manus. تتوافق صفحة اختيار الصف بصريًا على سطح المكتب والهاتف، بينما لا يمكن إثبات تطابق لوحة الدروس الأصلية دون حساب طالب تجريبي أو بيانات دخول يزوّدها مالك المنصة.
