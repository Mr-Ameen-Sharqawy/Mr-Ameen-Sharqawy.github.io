# VocFlashcard Students

هذه نسخة عامة ثابتة من منصة VocFlashcard للطلاب. تعمل على GitHub Pages دون خادم أو قاعدة بيانات، وتوفر اختيار الصف، التنقل بين الدروس، بطاقات المفردات، النطق من المتصفح، ومراجعة محلية محفوظة على الجهاز.

بوابة المعلم وحسابات الطلاب والتقدم المرتبط بالحسابات تبقى على نسخة المنصة الكاملة، لأن GitHub Pages لا يشغّل خادمًا أو قاعدة بيانات.

يُنشر ملف `index.html` وملف `assets/` الجاهزان مباشرة من جذر المستودع. ويظل `source-index.html` نقطة الدخول لتحديث البناء محليًا قبل نسخ مخرجات `dist/` إلى الجذر.
